Car Rental Management System in C

Project Overview

This project is a simple car rental management system developed in C as part of my first-year preparatory studies at EMSI (École Marocaine des Sciences de l'Ingénieur).

It allows users to manage car rental information through a menu-driven interface.

Features:

- Register car rental records
- Calculate the total rental cost
- Display rental reports
- List customers
- Search for rental records
- Modify the rental duration

Technologies Used:

- C programming language
- Structures
- Functions
- Conditional statements
- Loops

What I Learned

Through this project, I practised organizing a C program into functions, working with structures, managing user input, and implementing basic calculations and search operations.
